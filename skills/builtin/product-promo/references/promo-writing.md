# 宣传创作规则

> 教程让人"会用"，宣传让人"想用"。宣传只做一件事：让对的人在几秒内记住一个理由，并知道下一步做什么。

## 一、先定"一句话"，再写其他

1. **只选一个核心信息**（`message`）：读者看完只记得住一句话。它必须来自 `brief.md` 的价值主张，且有证据。
   好：「一个会记住你账号的内容搭档，从想法到发布都在一处」。坏：「强大的 AI 全能内容平台」。
2. **说给一个具体的人听**（`audience`）：写成"谁 + 在什么处境"，如「一个人运营三个平台、每天卡在选题上的创作者」。
3. **找到他的痛点**：用他自己会说的话，不用行业黑话。痛点必须具体到场景：「同一篇内容改三遍格式发三个平台」。
4. **定好行动号召**（`cta`）：一个动作，越小越好（「3 分钟装好试一次」好过「立即体验全部功能」）。

## 二、叙事结构

所有形态都按同一条线走，只是长短不同：

**钩子 → 痛点 → 转折 → 演示 → 证据 → 行动号召**

- **钩子**：结果先行或反常识，一句话、10 个字以内最好。不要以"你好""今天介绍"开头。
- **痛点**：最多 3 个，每个一行，读者要能对号入座。
- **转折**：一句话引出产品，说清"它怎么解决"，不是"它是什么"。
- **演示**：只展示 2–4 个最能支撑核心信息的功能，每个配真实界面画面。功能多也不要全上，挑。
- **证据**：数字、真实产物、可验证的事实（开源协议、支持的平台数等），每条都要能在 `brief.md` 里找到出处。
- **行动号召**：重复核心信息的关键词 + 一个具体动作 + 去哪里（网址、搜索词）。

## 三、文案规则

- 标题和画面文字：短句、动词、具体名词；一屏一个意思。
- 只写已验证或有文档的事实。没有数据就不写数字，不编用户量、增长率和对比结论。
- 禁用空洞形容词：强大、领先、革命性、极致、一站式赋能、颠覆。
- 禁用 AI 味句式：「在当今……的时代」「不仅……更是……」「让我们一起」。
- 对外文案不出现内部路径、密钥、模型名和"由 AI 生成"之类的措辞。

## 四、宣传文档

| 形态 | 用途 | 要点 |
|---|---|---|
| 落地页（HTML + 长图） | 官网、README、群里转发 | 首屏 = 核心信息 + 行动号召 + 主画面；往下依次痛点、功能、证据、上手步骤、再次行动号召 |
| 小红书卡片组（1080×1440） | 小红书图文 | 封面卡 = 钩子；每张功能卡只讲一件事 + 一张真实画面；最后一张是行动号召 |
| 竖版海报 | 朋友圈、社群 | 用 [poster-hero](../../poster-hero/SKILL.md)，文案取自 `promo.json` |
| 公众号 / 知乎长文 | 深度介绍 | 用 [copywriting](../../copywriting/SKILL.md) 按同一条叙事线写，配图用本技能截的真实画面 |

## 五、宣传视频

两种规格的节奏完全不同：

| | 竖版短片 | 横版介绍片 |
|---|---|---|
| 尺寸 | 1080×1920 | 1920×1080 |
| 时长 | 30–60 秒 | 60–120 秒 |
| 平台 | 抖音、视频号、小红书 | B 站、官网、发布会 |
| 节奏 | 每个镜头 1.5–3 秒，前 3 秒必须出钩子 | 每个镜头 3–6 秒，可以有完整的演示段落 |
| 口播 | 可无口播，靠大字幕 + 音乐；有口播时一句一镜 | 建议有口播，语速平稳 |
| 镜头数 | 10–18 个 | 12–24 个 |

镜头（`beats`）的写法：

- `hook`：一句钩子，字越大越好，最多两行。
- `pain`：一个痛点一个镜头。
- `screen`：一个功能一个镜头，标题说"得到什么"而不是"按钮叫什么"；有高亮的画面设 `zoom: true`，会先给全图再推近。
- `proof`：一个数字或事实，配一行来源。
- `cta`：产品名 + 行动号召 + 去哪里，停留至少 3 秒。

口播（`say`）比画面字多一点、更口语，但不要念出画面上已有的每一个字。

## 六、交付前自检

- 只看前 3 秒（视频）或首屏（文档），能说出这是什么、给谁用吗？
- 每个功能镜头/卡片，画面里真的能看到标题说的东西吗？
- 所有数字和事实都能在 `brief.md` 找到出处吗？
- 竖版画面里，截图上的字在手机尺寸下还看得清吗？看不清就设 `zoom` 或换裁切。
- 行动号召是否具体、出现了不止一次（文档首屏和末尾、视频结尾）？
- 有没有密钥、内部地址、真实个人信息出现在截图里？
